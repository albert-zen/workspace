# 全局索引（虚构模板）

使用者先与 Agent 约定实际保存位置，并在工作空间入口注明；这里仅展示内容角色，不需要填写所有栏目才开始。

## 当前目标与取舍
列已经确认的目标、优先级、有效授权和待决定事项；建议与决定分开。

## 事项入口
指向各 Work 的真实位置，说明承接者、当前结果、下一步、依赖和最近核对来源。细节继续由各事项维护，不复制完整正文。

## 跟进入口
需要持续跟进时，记录实际平台任务或通知入口、触发条件、回收方式与停止条件。未创建或未验证的安排明确标注，不把文件中的计划当成已运行。

## 覆盖与未知
说明已核对哪些来源、还有哪些范围没覆盖；不要把索引摘要当成实时事实。
