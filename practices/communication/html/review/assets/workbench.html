How to review

怎样审阅

  1. 先看主题。左侧按主题列出这次变更，颜色和排序优先展示仍待你决定的部分。
  2. 按块决定。每个主题下的 Markdown 场景或源码块都有“接受 / 不接受 / 待定”。只有接受的内容会进入最终文件。
  3. 按行批注。悬停行号点“+”，或选中一句话后点浮出的“批注选中文字”。批注随块保存，并在响应包里回传。
  4. 手改。“手改”只改当前块；保存后该块回到待定，需要你重新接受才会写入。
  5. 看案例。右侧列出这个主题引用的真实案例、反向对照和证据边界；没有任何来源也会如实写明。
  6. 准备应用。仍有待定块时按钮会停用；可逐个决定，或把剩余待定明确设为不接受。
