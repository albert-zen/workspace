# 协作、规划与上下文

简单任务由单个 Agent 直接闭环。只有工作跨多个步骤、需要多人/多 Agent 配合，或者跨回合推进时，才用这里的做法。

## 1. 对齐方案与验收

- **先查再聊，一次给全选择。** 先看代码、文档、数据和已有决定，再把影响方向的主要取舍、依据和推荐方案一次拿出来讨论，不要像填表一样逐题盘问。澄清复杂设计时，可按需参考 [外部参考 · Matt Pocock Skills](../references/references.md#matt-pocock-skills本地-submodule) 里的 `Grill Me` / `Grill With Docs`。
- **在规划时定好验收。** 动手前就想清楚两件事：做完了能看到什么现象？人怎么用最短路径确认没偏题？比如保存功能看“改完重开一致 + 并发冲突不丢输入”，研究任务看“结论到一手来源的核查路径”。不要等做完了再凑一个容易通过的标准。
- **把用户的原始意图留下来。** 复杂任务动工前，把我的核心诉求、关键原话和边界记在 Work 的 `## 事项说明` 里；需要保留原话或项目级长期意图时，直接用 `work intent add` 追加（不要自己用 shell 手搓文件路径和格式），方便后续接手者、独立 Reviewer 和 Inbox 界面直接查看。

## 2. 拆解执行与调度

- **按可验证的纵向切片拆 DAG。** 多步工作拆成可独立验证的结果并标出依赖；优先打通穿过真实边界的最小切片（比如先验证核心写入和冲突，再铺界面和迁移），别让并行 Agent 对着猜出来的接口干活。
- **有收益再派 Subagent。** 只有需要独立上下文、并行推进或独立判断（如 [独立 Review](review.md)）时才委派；任务小或耦合紧就自己干完。
- **派发时给够最小完整上下文。** 告诉对方：目标与原始意图、固定工作对象（分支/commit/文件路径）、写入边界（并行改代码用隔离 worktree，共享文档排好写入权）、验证要求和返回方式。
- **负责人自己做验收判断。** 回收下级结果时读完整报告和证据，不要只看一句“已完成”。阻塞时分清是缺事实、缺外部资源还是缺决策：能自己查的去查，能向上问的按层级咨询（执行者 → 事项负责人 → Chief → 我的 Inbox），不依赖它的部分继续推。

## 3. 用 Work 文件维护上下文

对于跨回合、需要交接或有重要决定的持续工作，用 `work` CLI 把上下文落到文件里，不要指望对话窗口记住一切。

### 常用入口

运行 `work`（或 `./bin/work`）查看入口，所有参数和细节以 `work <命令> --help` 为准：

- `work resume <项目/事项>`：只读接手当前上下文（默认折叠历史记录，`--full` 看全文）。
- `work start <项目/事项> --summary "..."`：新建或复用 Work，加 `--worktree` 可同时建隔离工作树；后续追加工作树用 `work add-worktree`。
- `work edit <项目/事项>` → 改副本 → `work save <副本>`：安全更新正文（自动带版本和冲突保护）。
- `work plan edit/save`：维护带版本和无环依赖校验的计划。
- `work record <项目/事项> --text "..."`：更新当前推进并追加执行历史。
- `work intent add <项目/事项> --text "..."`（或 `--project <项目>`）：以 append-only 方式追加用户原始意图与来源；`work intent show` 查看。
- `work pause` / `pause --needs-user` / `reopen` / `finish`：同步事项状态到 Inbox，并在 `finish` 时安全清理本事项创建且已合入的受管工作树。注意这些命令只改记录和视图，不会自动停止运行中的 Agent。

### 写好 Work 的几个要点

- **概览就能看懂现状**：`## 事项说明` 保留目标、原始意图、有效决定和验收方式（长期有效的约束别只写在会被覆盖的 `## 当前推进` 里）；`## 当前推进` 写清当前阶段、已验证成果、失败或限制、可用入口和下一步。本地、已合并、已部署要分清。
- **主动整理与压缩**：阶段切换、决定变化、准备交接或预计上下文压缩前，把重复过程收拢，把过时假设清掉，确保新接手的 Agent 只读这份入口就能明白“做什么、为什么、怎么验、卡在哪”。
- **接手前核实新鲜度**：先 `work resume`，再核对下一步要动的文件、Git 状态或 PR 状态。没查到的就标未知，不要拿旧摘要脑补现状。
- **跨任务记忆顺手记、不打断主线**：干活时如果发现值得留给后续 Agent 的环境约束或踩坑经验，按 [长期记忆](memory.md) 往 `memory/inbox/` 丢一条极简速记即可，不要中途停下来整理整个记忆库。
